# Lab 1: AWS Cloud Fundamentals

## Objective

The objective of this learning activity was to develop a foundational understanding of cloud computing and Amazon Web Services (AWS).

## Topics Covered

- Introduction to cloud computing
- Benefits of cloud computing
- AWS global infrastructure
- Regions and Availability Zones
- Cloud service models
- Shared Responsibility Model

## Key Learning Outcomes

Through this learning activity, I developed a better understanding of how cloud computing provides on-demand computing resources over the internet. I also learned about AWS global infrastructure and the importance of Regions and Availability Zones in providing reliable and scalable cloud services.

## Challenges

One challenge was understanding the differences between cloud service models and how AWS manages infrastructure responsibilities.

## How I Improved

I reviewed AWS learning materials, studied examples, and compared different cloud service models to better understand their purposes and responsibilities.
