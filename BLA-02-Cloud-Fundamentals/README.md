## Project Overview
[svg](#project-overview)

Welcome to my AWS Certified Generative AI Developer – Professional learning repository.

This repository documents my learning journey as I develop knowledge and practical skills in Generative AI, Amazon Web Services (AWS), Amazon Bedrock, Foundation Models, Retrieval-Augmented Generation (RAG), and cloud-based AI application development.

The purpose of this repository is to track my weekly learning progress, document hands-on activities, organize presentation materials, maintain study notes, and build a professional technical portfolio related to AWS Generative AI technologies.

This repository will be updated throughout my learning journey with weekly progress reports, presentation materials, hands-on activities, screenshots, study notes, architecture diagrams, project documentation, reflections, YouTube presentations, LinkedIn posts, and certification-related progress.
