# Weekly Learning Reflection

## Overview

This week's learning focused on improving the efficiency, responsiveness, and performance of Generative AI applications.

## Key Learning

I learned that Generative AI optimization involves more than selecting a model and sending prompts. Token consumption, context size, model capabilities, resource utilization, retrieval quality, and inference behavior can all influence application cost and user experience.

I explored how caching may reduce repeated processing when content can be reused, and how retrieval strategies can influence the relevance of information supplied to a model. I also reviewed reliability techniques such as exponential backoff and connection pooling.

The Amazon Bedrock and Cross-Region Inference topics expanded my understanding of performance and regional considerations in AWS-based AI systems.
